Abstract

Vision-Language-Action (VLA) models have emerged as a powerful paradigm for generalist robotic control. However, their high computational cost and limited control frequency hinder real-time manipulation, especially when large vision-language backbones and iterative action heads are executed at every control step. Existing acceleration methods mainly rely on static compression or input-level reduction, overlooking the non-uniform reasoning demands of sequential embodied control.

ElegantVLA is a plug-in phase-adaptive inference framework that accelerates VLA models through intra-model dynamic compute scheduling. A lightweight scheduler observes temporal representation similarity and robot states, then jointly allocates computation across the vision encoder, LLM, and action head. For perception-language reasoning, it selects among full computation, partial recomputation, and temporal reuse; for action generation, it reuses intermediate action-head states during stable motion while retaining full computation for precision-sensitive stages.

Extensive experiments on GR00T, CogACT, and real-world tasks show that ElegantVLA preserves or improves task success while substantially accelerating inference. It achieves up to 2.55x average speedup on GR00T and 3.77x average speedup on CogACT. In GR00T-based real-world experiments across six tasks, it reduces computation by 2.18x and increases control frequency from 13.8 Hz to 26.3 Hz.

Code

The GR00T-N1.6 implementation, a trained scheduler for the SimplerEnv Google Robot tasks, and the evaluation and two-stage training scripts are available at github.com/ChildTang/ElegantVLA. Quick start: 

git clone --recurse-submodules https://github.com/ChildTang/ElegantVLA.git
cd ElegantVLA
# set up the GR00T + SimplerEnv environment (see README), then:
bash scripts/install_gr00t_integration.sh
pip install -e .
MODEL_PATH=/path/to/GR00T-N1.6-fractal bash elegantvla/gr00t/scripts/eval_google_robot.sh
